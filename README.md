# 🔭 Геометриялық оптика мозаикасы

**Қазақ тіліндегі интерактивті рефлексия сайты**

Сабақ тақырыбы: **«Геометриялық оптиканың негізгі заңдары, толық ішкі шағылу, оптикалық құрылғылар»**.

Оқушылар телефондарымен QR-код арқылы кіріп, аты-жөнін және жауабын жазады. Әр жауап мозаиканың 6 бөлігін ашады. Мұғалімнің экранында нәтиже шамамен 3 секунд сайын жаңарып отырады.

## Жоба құрылымы

- `app.py` — негізгі Streamlit қосымшасы, SQLite, мозаика және мұғалім панелі.
- `style.css` — сайттың дизайны.
- `assets/optics.webp` — мозаикадағы иллюстрация (берілген визуалдық референстің оңтайландырылған нұсқасы).
- `requirements.txt` — кітапханалар.
- `.streamlit/config.toml` — сайттың түстері.
- `.streamlit/secrets.toml.example` — әкімші құпиясөзінің үлгісі.

## Компьютерде іске қосу

```bash
pip install -r requirements.txt
streamlit run app.py
```

Негізгі экран: `http://localhost:8501/`

Оқушы парағы: `http://localhost:8501/?view=student`

Мұғалім панелі: `http://localhost:8501/?view=admin`

**Маңызды:** телефонмен QR сканерлеу үшін сайтты Streamlit Community Cloud-та жариялаған дұрыс. `localhost` QR-коды басқа телефонда ашылмайды.

## Streamlit Community Cloud-қа жариялау

1. GitHub-та `geometrialyk-optika-mozaikasy` деген жаңа репозиторий жасаңыз.
2. Осы жобадағы **барлық файлдарды**, соның ішінде `assets` және `.streamlit/config.toml` файлдарын репозиторийге жүктеңіз.
3. [share.streamlit.io](https://share.streamlit.io/) сайтында `Create app` → репозиторийді таңдаңыз.
4. `Main file path` — `app.py`.
5. `Settings` → `Secrets` бөліміне мынаны енгізіңіз (өз құпиясөзіңізді пайдаланыңыз):

```toml
ADMIN_PASSWORD = "my-strong-private-password"
```

6. `Deploy` басыңыз. Жарияланған сайттың URL мекенжайымен QR-код автоматты түрде жасалады.

## Мұғалім панелі

- URL: `?view=admin`.
- Барлық жауаптарды CSV файлында сақтау.
- Бір жауапты жою.
- Жаңа сабақ алдында барлық жауаптарды тазалау.

## Мозаиканы баптау

`app.py` басында:

```python
COLS, ROWS = 15, 10
PIECES_PER_ANSWER = 6
```

Барлығы 150 фрагмент, 25 жауаптан соң толық ашылады. `COLS`, `ROWS` өзгерсе, суреттің өлшемі мен `mosaic_svg` координаттарын да сәйкестендіру қажет. Бір оқушы бірден бірнеше жауап жібермеуі үшін сабақ барысында мұғалім нұсқау бергені дұрыс.

## Деректер туралы

Жауаптар **SQLite жергілікті базасында** сақталады. Streamlit Community Cloud тегін орналастыруында бұл **тұрақты сақтау орны емес**: бағдарлама қайта іске қосылса, жауаптар жоғалуы мүмкін. Оқу сабағы соңында CSV экспортын жүктеп алыңыз. Көп сабақ бойы тұрақты сақтау үшін сыртқы дерекқор қажет.
